The Configure UI is a first-party screen (not only the declarative form):

- **Paused** — temporarily stop grabs while the worker stays activated.
- **Dry-run** — match filters without enqueueing.
- **Watch directories** — paths under download roots polled for `.torrent` / magnets.
- **IRC servers** — host, port, TLS, nick, channels; each server can be enabled independently.
- **Filters** — title/regex/label rules per server or channel; each filter can be enabled independently.
- **Export / import** — JSON of IRC servers + filters (secrets omitted on export).
